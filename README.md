# Gurgaon Real Estate Market Analysis

## Project Overview

This project analyzes the Gurgaon real estate market using 14,000+ property listings.

The objective is to understand property pricing, demand patterns, BHK distribution, locality-wise pricing, builder performance, RERA approval status, and property status.

## Tools & Technologies

- Python – Data Cleaning & Exploratory Data Analysis
- SQL / MySQL – Data Storage & Analysis
- Power BI – Interactive Dashboard & Visualization
- DAX – Analytical Measures

## Key Insights

- 3-BHK properties represent the largest segment in the dataset.
- Sector 65 has the highest property listing concentration among the top localities.
- Baliawas and Sector 42 are among the highest-priced localities.
- Average property price increases with higher BHK categories.
- Approximately 63% of the property value is associated with RERA-approved properties.
- Ready-to-move properties represent approximately 55% of the listings.
- Resale properties have the highest average price among the major property-status categories.
- Property prices show a highly right-skewed distribution, with a small number of high-value properties.
